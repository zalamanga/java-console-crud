# Asal proyek

Melanjutkan `CRUD-java-console1-main` dari proyek NetBeans lokal. Source asal mencantumkan penulis **midha**. Contoh tambah, tampil, ubah nomor telepon, dan hapus data digabung menjadi satu menu konsol, dengan repository JDBC dan validasi terpisah.

Schema contoh dibuat kembali dari nama kolom pada query asal. Tidak ada akun, data pengguna, password mentah, hasil build NetBeans, atau database asli yang disalin ke repository ini. Dependency MySQL Connector/J dan alat build memiliki lisensi masing-masing. Tidak ada lisensi menyeluruh baru yang ditambahkan atas sumber asal.
